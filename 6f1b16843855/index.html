Send path A — Gmail mail merge (if her account shows the toggle)

  1. Upload gmail-merge-recipients.csv to Google Sheets (File → Import) in HER Google account
  2. Gmail → Compose → click the mail-merge icon (person+) at the right of the To field → Link a spreadsheet → pick the sheet
  3. Paste the subject and body below — the @First name tag personalizes each send
  4. Drag header.png into the body, top position, before the text
  5. Select the body text after pasting → set font to Georgia (matches brand serif)
  6. Make "See the journey" a link: select the line → ⌘K → paste the journey URL
  7. Preview → send yourself the test → open it on a phone → then Send All
